# 小红书招聘发布参考

小红书没有供本技能直接调用的公开发布 API。发布操作通过创作者平台网页完成，
具体流程和限制以 `../assets/rules.md` 为准。

## 入口与前提

- 创作者平台：`https://creator.xiaohongshu.com/`
- 发布页面：`https://creator.xiaohongshu.com/publish/publish`
- 操作前必须由用户完成登录；不得尝试绕过验证码或平台安全机制。
- 发布前必须让用户确认文案、图片和目标账号。

## 网页自动化注意事项

1. 选择“上传图文”标签，确认未进入视频发布模式。
2. 通过 `input[type="file"]` 或页面提供的上传按钮添加图片。
3. 等待图片全部上传完成，再填写标题和正文。
4. 标题不超过平台限制，正文不得包含歧视、虚假承诺或敏感招聘条件。
5. 点击发布后检查按钮状态、页面跳转和成功提示，不能仅以点击动作判断成功。
6. 页面结构可能变化；选择器失效时，应重新检查可见页面，而不是猜测 DOM。

## 失败处理

- 登录失效：停止操作，请用户重新登录。
- 上传失败：保留原图片，报告失败文件和页面提示后重试。
- 标题或正文被拒绝：根据页面提示调整，并再次让用户确认。
- 发布状态不明确：检查作品管理页；在确认前不得重复发布。

## 安全边界

- 不保存用户密码、Cookie 或验证码。
- 不自动接受平台协议或授权变更。
- 不在用户未确认时执行最终发布。
- 不以脚本规避频率限制、风控或内容审核。
