# 工作流模式

## 顺序工作流

对于复杂任务，应拆分为清晰的连续步骤，并在 `SKILL.md` 开头附近概述完整流程：

```markdown
填写 PDF 表单需要以下步骤：

1. 分析表单（运行 `analyze_form.py`）。
2. 创建字段映射（编辑 `fields.json`）。
3. 验证映射（运行 `validate_fields.py`）。
4. 填写表单（运行 `fill_form.py`）。
5. 验证输出（运行 `verify_output.py`）。
```

## 条件工作流

对于包含分支逻辑的任务，应明确说明每个决策点：

```markdown
1. 判断修改类型：
   **创建新内容？** → 执行下方“创建工作流”
   **编辑现有内容？** → 执行下方“编辑工作流”

2. 创建工作流：[步骤]
3. 编辑工作流：[步骤]
```
