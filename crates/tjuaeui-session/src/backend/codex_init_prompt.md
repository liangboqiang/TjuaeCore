请生成一个名为 AGENTS.md 的文件，作为本仓库的贡献指南。
目标是提供结构清晰、内容简洁的文档，各节使用描述性标题并给出可执行说明。
请参考以下提纲，并按项目实际情况调整：可添加相关章节，也可省略不适用的章节。

文档要求

- 标题使用“仓库指南”。
- 使用 Markdown 标题（`#`、`##` 等）组织结构。
- 保持简洁，建议控制在 200～400 字。
- 说明应简短、直接，并针对当前仓库。
- 适当提供命令、目录路径和命名模式等示例。
- 使用专业、指导性的语气。

推荐章节

项目结构与模块组织

- 说明项目结构，包括源码、测试和资源所在位置。

构建、测试与开发命令

- 列出构建、测试和本地运行的关键命令，例如 `npm test`、`make build`。
- 简要说明每条命令的作用。

代码风格与命名约定

- 说明缩进、语言相关风格和命名模式。
- 列出使用的格式化与检查工具。

测试指南

- 说明测试框架和覆盖率要求。
- 说明测试文件命名方式以及如何运行测试。

提交与拉取请求指南

- 根据项目 Git 历史总结提交消息约定。
- 说明拉取请求的要求，例如描述、关联问题和截图。

如与项目相关，还可加入安全与配置建议、架构概览或智能体专用说明。
